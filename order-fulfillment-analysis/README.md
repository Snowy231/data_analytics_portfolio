# 📊 Order Fulfillment Performance Analysis

**Analysis of Unsuccessful Orders by Product, Payment Method, Acquisition Channel and Time Period**

---

## 🎯 Project Overview

This project analyzes order fulfillment performance to identify the factors associated with unsuccessful orders.

The objective was to help management understand which products, payment methods, acquisition channels, and time periods were associated with the highest rates of unsuccessful orders.

**An order was classified as:**
- **Successful:** Delivered
- **Unsuccessful:** Cancelled or Returned
- **In Progress:** Pending or Shipped

---

## 📈 Key Metrics

| Metric | Value |
|--------|-------|
| Total Orders | 1,200 |
| Unsuccessful Orders | 497 |
| Unsuccessful Order Rate | 41.42% |
| Value of Unsuccessful Orders | $519,673.91 |
| Unsuccessful Order Value Rate | 41.09% |

---

## 🔍 Key Findings

- **Overall** unsuccessful order rate is **41.42%**, representing **$519,673.91** (41.09% of total order value).
- **April 2025** recorded the highest unsuccessful rate at approximately **68.75%**, significantly above the overall average.
- **Monitor** has the highest unsuccessful rate (**43.56%**) among products.
- **Laptop** and **Tablet** together account for **$166.6k (32%)** of unsuccessful order value.
- **Tablet** has the highest number of returns (**43**).
- **Gift Cards** have the highest unsuccessful rate (**44.35%**) among payment methods.
- **Instagram** has the lowest unsuccessful rate (**37.07%**) among acquisition channels.

---

## 💡 Recommendations

- Investigate the operational issues that occurred in **April 2025** to prevent recurrence.
- Prioritize root-cause analysis for **Laptop** and **Tablet** orders, given their high financial exposure.
- Investigate the high return rate for **Tablet** orders.
- Review **Gift Card** transactions and related processes.
- Monitor and replicate best practices from **Instagram** channel performance.
